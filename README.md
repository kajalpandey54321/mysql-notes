# MySQL Notes

## 1. What is MySQL?

MySQL is an open-source Relational Database Management System (RDBMS).

### Features of MySQL

- Open-source
- Fast and reliable
- Easy to use
- Supports SQL
- Used to store and manage data

## 2. What is Database?

A database is an organized collection of data.

### Example

A Student Database can contain:

| ID | Name | Course |
|----|------|--------|
| 1 | Kajal | CSE |
| 2 | Rahul | CSE |

## 3. What is SQL?

SQL stands for Structured Query Language.

SQL is used to create, store, retrieve, update and delete data in a database.
